# oh-hell

Scorekeeper for the card game Oh Hell. One Expo / React Native (TypeScript)
codebase ships three surfaces:

- **Web**: static export (`expo export --platform web`), deployed to GitHub
  Pages at `/oh-hell` by `.github/workflows/pages.yml`.
- **Desktop**: an Electron window around the same static export
  (`nix/desktop.nix`, `nix/desktop/main.js`), Linux via nix.
- **Android**: Expo native build. `android/` is generated by `expo prebuild`
  and not committed; app config lives in `app.config.js`.

There is no backend. Games live on the device in AsyncStorage (localStorage on
web and desktop). Modeled on `mova` (`~/projects/mova`); look there first for
Android release, F-Droid, and desktop packaging pieces.

## Structure

```
app/          # expo-router screens: index (games), new (setup), game/[id]
components/   # UI pieces (hand entry, scoreboard, rules editor, ...)
context/      # GamesProvider: in-memory games + persistence
lib/
  rules.ts    # rule parameters + pure scoring/schedule/bidding functions
  presets.ts  # named rule sets
  game.ts     # stored game shape + everything derived from it
  storage.ts  # AsyncStorage layer
  format.ts   # display strings
tests/        # jest unit tests for lib/
nix/          # web + desktop packages
```

## Invariants

- Scoring and game logic live only in `lib/` (rules, presets, game). UI code
  must not reimplement any of it; if a view needs a derived value, add a
  function to `lib/` and consume that.
- A stored `Game` holds only what was entered: a copy of its rules, players in
  seat order, the first dealer, finished hands' bids/tricks, and the in-progress
  draft. Scores, totals, dealer, and legal bids are always recomputed.
- The deck is always 52 cards.
- `nix/web.nix` pins the yarn dependency hash; update it whenever `yarn.lock`
  changes (`nix run nixpkgs#prefetch-yarn-deps -- yarn.lock`, then
  `nix hash convert --hash-algo sha256 --to sri <hash>`).

## Development

- Use the direnv environment. Outside it, run `direnv exec . <cmd>` from the
  repo root rather than `nix develop -c`.
- Android work needs `nix develop .#android` (SDK/NDK/JDK).
- `just check` runs prettier, alejandra, eslint, tsc, and jest. CI runs the same
  thing plus `nix build .#web .#desktop`.
- `just web` (dev server), `just web-build`, `just desktop`, `just android`.
